# Documentation Map

This directory explains how to read the repository.

---

## Binding Documents (Authoritative)

These define what Sages Stone *is*:

- Protocol specifications
- Formal laws and constraint definitions
- Architectural invariants

If a document describes a rule or law, it is binding.

---

## Explanatory Documents (Interpretive)

These explain *how* or *why*:

- System overviews
- Architectural narratives
- Worked examples and commentary

They must not contradict binding documents.

---

## Public / Business Documents

These govern use, distribution, and adoption:

- Licensing
- Business model
- Installation and deployment guides

They do not define technical truth.

---

## Rule of Thumb

When in doubt:
**treat protocol documents as canonical and everything else as commentary.**
