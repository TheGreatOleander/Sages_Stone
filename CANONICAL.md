# CANON — Sages Stone

This repository is a **canonical reference object**, not an application framework.

It encodes constraints, invariants, and reduction laws that may be
*implemented*, but not *reinterpreted*.

---

## Axiomatic (Must Never Change)

The following are invariant and define the identity of Sages Stone:

- Reduction–Constraint Formalism (RCF)
- Dimensional projection and collapse laws
- Constraint preservation rules defined in protocol specifications
- Any invariant explicitly marked as such in protocol documents

A change to these is not an evolution — it is a fork.

---

## Derivative (May Evolve)

These are sanctioned realizations of the axioms:

- Language-specific implementations
- Execution engines and runtimes
- Simulation, visualization, and analysis tooling
- Optimization strategies

They must obey the axioms but may change freely.

---

## Replaceable (Non-Canonical)

These exist for usability, adoption, or deployment:

- Orchestration strategies
- Integration adapters
- Business, licensing, and distribution scaffolding
- Installation and packaging logic

Removal or replacement of these does not affect the canon.

---

## Interpretation Rule

If there is ever a conflict between:
- code and protocol
- narrative and formal spec
- implementation and invariant

**the protocol specification is authoritative.**
