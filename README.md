# Sage's Stone

**A sane, complete exploration of constraint and emergence.**

[![Support with Crypto](https://img.shields.io/badge/Support-Crypto%20Tip-5A31F4?logo=ethereum&logoColor=white)](https://github.com/TheGreatOleander/Sages_Stone#support)


This repository is intentionally layered:

- `systems/` — canonical engine (always runs)
- `demos/` — runnable value demonstrations
- `examples/` — educational snippets
- `research/` — exploratory work (may not run)
- `archive/` — preserved history (frozen)

---

## Quick Start

```bash
pip install -e .
python demos/demo_basic.py
```

If that works, everything important works.
